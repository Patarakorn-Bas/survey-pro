# สำรวจและวางผัง Pro

แอปงานสำรวจสำหรับวิศวกรโยธา: วงรอบและระดับปรับแก้ Least Squares, ตารางระดับแปลงที่ดิน (ขุด–ถม), COGO, วางผัง, TIN คอนทัวร์, ปริมาตรดิน ส่งออก DXF / PDF ใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| index.html | ตัวแอปทั้งหมด |
| manifest.webmanifest | ข้อมูลสำหรับติดตั้งเป็นแอป |
| sw.js | ทำให้ใช้งานออฟไลน์ได้ |
| icon-*.png | ไอคอนแอป |

## ขึ้น GitHub Pages
1. สร้าง repository ใหม่ เช่น `survey-pro` (Public)
2. Add file › Upload files › ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (วางไว้ที่ระดับบนสุด ไม่ต้องมีโฟลเดอร์ซ้อน) › Commit
3. Settings › Pages › Source: Deploy from a branch › Branch: `main` / `(root)` › Save
4. รอ 1–2 นาที เปิด `https://<ชื่อผู้ใช้>.github.io/survey-pro/`

## อัปเดตเวอร์ชัน
อัปโหลด `index.html` ใหม่ทับไฟล์เดิม ผู้ใช้จะได้เวอร์ชันใหม่เมื่อเปิดแอปตอนมีสัญญาณ (ข้อมูลโครงการในเครื่องไม่หาย)

## ข้อมูล
ข้อมูลเก็บในเบราว์เซอร์ของแต่ละเครื่อง สำรองด้วย เมนูส่งออก › บันทึกโครงการ (.json)
